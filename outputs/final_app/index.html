추천의 해석

추천은 입력한 조건에 따른 가동 일정 후보입니다. 실제 생산량, 설비 안전, 품질, 현장 작업 가능 여부를 운영자가 확인한 뒤 적용해야 합니다. 이 화면에서 설비를 직접 제어하지 않습니다.

데이터와 모델

최종 LightGBM 예측과 15분 최대 직접 P90 경보를 사용합니다.

예측 CSV 입력 형식

날짜는 date, 날짜, dt 중 하나를 사용합니다. hour, pred, pred_max15, pred_hi_max15, alarm_threshold 열과 하루 24개 시간 행이 필요합니다. 경보는 P90과 기준을 비교해 다시 계산합니다.
