 G. 피처 세트 시나리오
--------------------------------------------------------------
  시나리오 1  테스트에 생산계획·기상 제공     A + B + C + D
  시나리오 2  테스트에 달력·과거 전력만 있음  A + D
  → 테스트 데이터 형태가 미확인이므로 두 세트 모두 준비

 H. 구현 (src/features.py → outputs/features.csv)
--------------------------------------------------------------
  세트 이름    FEATURES['full'] (32개) = A + B + C + D
               FEATURES['no_plan'] (17개) = A + D
  열 이름      A  hour, dow, is_weekend, is_off, after_off, shift(0 야간/1 점심/2 주간),
                  is_transition, month
               B  prod, prod_cap(800 상한), prod_log, prod_zero, day_prod, day_prod_hours,
                  prod_prev, prod_next, prod_diff (앞뒤 시간은 당일 안에서만)
               C  cool(= max(0, 기온 - 22)), temp, humid, thi(불쾌지수), wind, rain
               D  lag24, lag168, lag336, lag_week_mean4(최근 4주 같은 요일·시각 평균),
                  lag_prev_op(직전 가동일 같은 시각), prev_day_mean/max, last_week_day_mean/max
  메타 열      dt, 날짜, target, target_max15, is_clone, is_off, is_stop, is_corrupt,
               train_ok (학습에 쓸 행 = 가동 중단·기록 손상 제외)
  누수 검증    특정 날 전력값을 바꿔도 그날 피처는 변하지 않음 (다음날 lag만 변함) 확인

 I. 실제 모델 결과로 본 피처 (2026-09-22, 작업내역 [10])
--------------------------------------------------------------
  ▷ 피처 세트 비교 (고유일 개발 폴드 MAE)
      LightGBM  full 14.3 / no_plan 15.7
      Ridge     full 19.4 / no_plan 16.9 (Ridge는 no_plan이 더 좋음, 단 피크 MAE는 full 12.7이 최고)
      → 생산계획은 도움이 되지만 없어도 대응 가능

  ▷ LightGBM 변수 중요도 (full 세트, 전 폴드 평균 gain 비율)
      prod 30.9% / lag168 18.3% / lag_week_mean4 6.8% / lag336 6.5% / shift 6.3% /
      is_off 5.3% / prod_cap 2.8% / month 2.4% / day_prod 2.3% / lag24 2.0%
      (전체 목록: outputs/models/lgbm/feature_importance.csv)

  ▷ 중요도가 거의 0인 피처 (0.1% 미만)
      cool, after_off, is_transition, is_weekend, prod_log, prod_zero
      이유 추정
        - prod_log, prod_zero: prod를 단조 변환한 값이라 결정나무에는 새 정보가 없음
          (선형 모델 Ridge에는 의미 있음)
        - cool: temp에서 22°C 기준을 나무가 직접 찾을 수 있음
        - is_weekend: dow로 대체, is_transition: hour로 대체
        - after_off: lag_prev_op, 결측 처리된 lag가 이미 휴무 다음날 정보를 담음
      → 결정나무용으로는 빼도 성능 영향이 작을 것. 단 Ridge·해석용으로는 유지 권장
      → 제거 여부는 설정 조정 단계에서 실험으로 확인
