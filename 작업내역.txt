  ▷ 베이스라인이란?
      머신러닝 모델 이전에, 단순 규칙만으로 예측했을 때의 오차 기준점.
      앞으로 만들 모델은 이 값보다 좋아야 의미가 있음 (보고서 '2개 이상 모델 비교' 항목에 사용)

      베이스라인 4종 (예측 방법)
        global_mean   학습 기간 전체 평균값으로 항상 예측
        lag24         어제 같은 시간의 전력을 그대로 사용
        lag168        지난주 같은 요일·같은 시간의 전력을 그대로 사용
        요일x시간 평균  학습 기간의 (요일, 시간대)별 평균값 사용

      outputs/baseline_results.csv 구성 (4종 x 5개 검증월 = 20행)
        model    베이스라인 이름
        fold     검증한 월 (해당 월 이전 데이터만 학습에 사용 → 미래 누수 방지)
        MAE      평균 절대오차 (실제와 예측의 차이 평균, 작을수록 좋음)
        RMSE     큰 오차에 더 민감한 지표
        peakMAE  전력 상위 5%(피크) 시간에서만 잰 MAE (피크 예측력 확인용)
        n        해당 월의 시간 수
      → 목표: 모델이 MAE 18.2, 피크 MAE 37.3 (각 최저 베이스라인)을 넘을 것

  ▷ 예측 조건 확정 : 24시간 앞(day-ahead)  ※ 대회 공지에 명시 없어 팀 합의로 결정
      예) 오늘 18시에 내일 0~23시 전력을 한 번에 예측
      이유: 과제 목표가 '생산일정 조정으로 피크 저감'이므로 전날에는 예측이 나와야 함
      사용 가능 정보: 어제까지의 전력 실적 + 내일의 요일/생산계획/기온예보
      보조: 보고서에 1시간 앞, 1주 앞 오차도 참고용으로 함께 제시 (창의성 항목)
      ※ 테스트 파일에 생산량/기온이 들어있는지는 여전히 미확인

  ▷ 산출물 : src/pattern.py → outputs/daily_pattern.csv (날짜별 패턴 ID)

  ▷ 반복 패턴 분석 결과 (24시간 전력 곡선이 완전히 같은 날끼리 묶음)
      - 257일 중 고유 패턴 141개, 2일 이상 반복되는 패턴 45개
      - 반복 크기: 15일 x1개 / 7일 x1 / 6일 x2 / 5일 x2 / 4일 x11 / 3일 x17 / 2일 x11
      - 가장 큰 반복(15일) = 가동 없는 날의 평탄 곡선 (전력 ~22, 생산량 0)
        → 일요일뿐 아니라 평일(화·수·금)에도 무가동일이 존재
      - 그 외 반복은 '토요일형'(평균 46) / '평일 가동형'(평균 121~125) 곡선이
        여러 날에 걸쳐 복제된 형태

  ▷ 월별 분포 (핵심)
      월          1월   2월   3월   4월   5월   6월   7월   8월   9월
      반복일       27    28    29    30    17    28     2     0     0
      고유(1회)일   4     0     2     0    14     2    29    31    14
      (8·9월은 전부 고유 패턴)
      → 1~6월은 곡선이 복제된 증강 데이터 성격, 7~9월은 매일 다른 실제 데이터 성격

  ▷ 시사점
      1) lag168이 6월에 MAE 6.7로 좋았던 건 복제 때문 (실력이 아님).
         7~9월(고유 패턴) 성적이 실제 예측력에 더 가까움
      2) 테스트 구간(9/15~)은 7~9월과 같은 성격일 가능성이 커 → 검증 폴드 중
         7·8·9월 결과를 더 중시하고, 학습 시 1~6월 복제일이 과대 반영되지 않게 주의
      3) 복제된 날은 생산량이 달라도 전력 곡선이 같음(일 생산량 변동계수 평균 0.43)
         → 1~6월 구간의 생산량-전력 관계는 실제보다 노이즈가 많을 수 있음
      4) 전환점(패턴이 바뀌는 횟수) 241회 → 전날과 같은 패턴인 날은 거의 없음
         (전날 복제가 아니라 '주 단위/떨어진 날짜' 복제)
