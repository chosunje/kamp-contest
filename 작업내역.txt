==============================================================
 KAMP 프로젝트 작업 내역 (팀 공유용)
 과제: ⑤ 제조 생산데이터 기반 전력사용량 예측 및 최대피크 위험조건 분석
 기준일: 2026-09-22  (현재 상태 스냅샷, 이전 기록은 이 문서로 대체)
==============================================================

■ 한눈에 보기
  1. 데이터: 2021-01-01 to 09-14, 시간 단위 6,168행 (257일 x 24시간, 누락 없음)
  2. 257일 중 161일은 전력곡선이 다른 날에서 통째로 복사된 "복제일" (증강 데이터)
     - 1 to 6월에 몰려 있고 7 to 9월은 거의 전부 "고유일"
     - 전력만 복사되고 생산량·기상은 복사되지 않음 → 복제일은 생산과 전력이 서로 안 맞음
     → 앞으로 모든 분석·시각화·학습·평가는 복제일/고유일을 나눠서 본다
  3. 전력을 좌우하는 변수는 생산량(= 공장인원, 사실상 같은 정보)
     - 생산량 약 800에서 전력이 포화 (더 만들어도 전력이 안 오름)
     - 기온은 전체 상관은 약하지만, 가동 시간만 보면 22°C 이상에서 전력 상승 (냉방 추정)
  4. 전력은 세 상태로 나뉨: 기저부하 약 23 / 중부하 약 105 / 고부하 약 165
  5. 피크(상위 5%)는 평일 8 to 9시, 11시, 13 to 14시와 7월 말에 집중
     - 요금 기준 피크는 15분 단위 최대값일 가능성이 높고, 시간 평균보다 평균 7.3 높음
  6. 가장 강한 베이스라인: lag168(지난주 같은 시각) MAE 18.2
     단, 복제를 분리하지 않은 결과라 과대평가됐을 가능성이 큼 (재계산 필요)
  7. 예측 조건은 팀 합의로 24시간 앞(day-ahead). 테스트 데이터 형태는 아직 아무도 모름

  현재 단계: EDA·베이스라인 완료 → 다음은 복제 분리 평가 + 피처 엔지니어링 + 모델 구현

 [4] 복제(증강) 데이터 ★ 가장 중요
--------------------------------------------------------------
  ▷ 정의
      24시간 전력곡선(평균값 24개)이 다른 날과 완전히 같은 날 = 복제일.
      원본이 어느 날인지는 구분할 수 없으므로 그룹 전체를 복제일로 본다.

  ▷ 규모
      복제일 161일 (45개 그룹) / 고유일 96일
      월     1월  2월  3월  4월  5월  6월  7월  8월  9월
      복제    27   28   29   30   17   28    2    0    0
      고유     4    0    2    0   14    2   29   31   14

  ▷ 복제 방식에 대한 증거
      - 15분 세부값까지 통째로 같음 (160일)
      - 기온곡선이 같은 날은 0일 → 기상은 실측값 그대로
      - 생산량이 있는 날 중 생산곡선이 같은 날은 0일 → 생산량은 복사되지 않음
        (생산곡선이 같은 64일은 모두 생산량이 하루 종일 0인 날)
      - 그룹 45개 중 24개(78일)는 "다른 달의 같은 날짜"끼리 묶임
        예) 1/11, 2/11, 3/11, 6/11 전력곡선 동일. 그런데 2/11은 생산량 0, 3/11은 17,899
      - 그룹 내 요일까지 같은 경우는 16%뿐 → 요일도 무시하고 복사됨

  ▷ 시사점
      - 복제일에는 "생산은 많은데 전력은 평탄" 같은 모순된 행이 섞여 있음
        → 그대로 학습하면 모델이 생산량 효과를 약하게 배움
        (전력-생산량 상관: 복제일 0.72 / 고유일 0.79)
      - 랜덤 분할 금지. 같은 곡선이 학습·검증에 동시에 들어가 점수가 부풀려짐
      - 테스트 구간(9/15 이후 추정)은 7 to 9월처럼 고유일 성격일 가능성이 큼
        → 실제 예측력은 고유일(7 to 9월) 성적으로 판단
      - 학습 방식 후보: 복제일 가중치 낮추기 / 복제일 제외 / is_clone 플래그 투입 → 비교 필요

 [5] 전력 패턴
--------------------------------------------------------------
  ▷ 요일
      평일 평균 103 to 123, 토 51, 일 41. 생산량은 일요일 0, 토요일은 평일의 1/8 수준
  ▷ 시각 (고유일 기준)
      - 평일 8 to 11시, 13 to 19시 고부하. 12시 점심에 하락
      - 화 to 토 새벽 1 to 6시에도 약 90 (야간 가동). 월요일 새벽은 기저부하
      - 토요일은 새벽 1 to 6시만 가동하고 8시 이후 기저부하
  ▷ 분포
      기저부하 약 23 (무가동) / 중부하 약 105 / 고부하 약 165 세 덩어리
      → 연속값 회귀보다 "가동 상태" 전환을 잘 맞히는 게 핵심일 수 있음
  ▷ 무가동일
      - 일요일 외에 1월 화·수, 3월 금요일에도 평일 무가동 (모두 복제일)
      - 7/31 to 8/8 연속 휴무 (고유일, 하계휴가 추정)
  ▷ 자기상관
      1시간 전 0.90 / 1일 전 0.37 / 1주 전 0.74
      → 요일 패턴이 강해 "전일"보다 "전주 같은 요일" 값이 유효

 [6] 영향 변수 (스피어만 상관: 순위 기반 상관, 곡선 관계도 잡음)
--------------------------------------------------------------
  ▷ 전력과의 상관          복제일    고유일
      생산량                0.72      0.79
      공장인원              0.66      0.77
      인건비               -0.27     -0.22    (= 낮 시간대 여부)
      풍속                  0.13      0.12
      기온                  0.15      0.04
      습도                 -0.11     -0.08
      전기요금              0.11     -0.02
      강수량               -0.03      0.09

  ▷ 해석
      - 생산량과 공장인원은 0.99로 사실상 같은 변수 → 둘 중 하나만 써도 됨.
        둘 다 넣으면 SHAP 중요도가 둘로 나뉘어 보이니 해석 시 주의
      - 전기요금은 기온과 0.67 to 0.77 → 둘 다 계절을 나타냄
      - 생산량 구간별 평균 전력 (생산량>0, 5분위)
          85 이하: 103 / 85 to 292: 106 / 292 to 742: 131 / 742 to 1,371: 154 / 1,371 초과: 152
        → 약 800 이후 포화
      - 기온: 전체 상관은 낮지만 가동 시간(전력>40)만 보면 22°C 이상에서
        110 → 165 to 175로 상승 (두 그룹 모두). 가동·무가동이 섞여 상관이 가려졌던 것
        → "기상 영향 약함"이라는 이전 결론은 수정. 여름 냉방 부하 피처 검토

 [7] 생산량 0인데 전력을 쓰는 시간
--------------------------------------------------------------
  - 생산량 0인 시간 2,657개, 전력 중앙값 23 (= 기저부하)
  - 그중 전력 >100인 시간 471개. 공장인원도 전부 0, 모든 시간대에 퍼져 있음
  - 생산-전력 시차 상관은 시차 0에서 최대 → 기록 시각이 밀린 것은 아님
  - 471개 중 71%(335개)는 복제일 → 대부분 증강 부작용
  - 나머지 136개(29일, 7월 집중)의 실제 원인 후보
      기저부하(공조·조명·컴프레서) / 여름 냉방 / 비생산 가동(금형 교체·세척·점검) /
      연속 공정 설비 / 생산 기록 누락
  → "예측오차가 크게 나는 생산조건" 분석(배점 3번)의 1순위 후보

 [8] 피크
--------------------------------------------------------------
  ▷ 시간 평균 기준 상위 5% (전력 177 이상)
      시각   8시 63 / 9시 61 / 14시 59 / 11시 55 / 13시 54건
      요일   월 to 금 위주, 토요일 3건
      월     7월 104 > 8월 57 > 3월·6월 45
      일 최대 상위: 7/27 to 7/30 (207 to 208), 7/21 (204) → 7월 말, 여름 요금(191.6) 기간
  ▷ 피크 조건
      피크 시 생산량 평균 1,158 (비피크 426), 공장인원 1.57 (0.86), 기온 20.6 (15.6)
      단, 생산량 상위 10% 시간의 86.7%는 피크가 아님
      → 생산량 단독이 아니라 설비 동시가동·기온 등 조합 조건이 결정
  ▷ 15분 최대 vs 시간 평균
      - 한국 최대수요전력은 15분 단위 → 15/30/45/60분 중 최대값이 요금 기준 피크에 가까움
        (15분 컬럼이 15분 평균인지 순간값인지는 확인 필요)
      - 15분 최대 - 시간 평균: 평균 7.3, 중앙 5, 최대 67
      - 차이가 큰 시각: 7시 19.7, 17시 17.9, 12시 12.4 → 출근·점심·퇴근 전환 시각
      - 시간 평균 기준과 15분 최대 기준 피크 겹침 84%, 일 피크 시각 일치 56%
      - 시간대별 비율로 평균 → 15분 최대 환산 시 오차 7.31 → 2.86
      → 모델은 시간 평균을 예측하고, 시간대별 계수로 15분 최대를 환산하는 2단계 구조 가능
      → 서브 개발자의 피크 분석·스케줄링은 15분 최대 기준으로 하는 것을 권장
  ▷ 스케줄링 제약
      피크 시간대 부하를 야간으로 옮기면 인건비 계수 1.0 → 1.5
      → "전기요금 절감 vs 인건비 증가" 트레이드오프가 저감방안의 핵심
